#+title: Shared Voice Interface

One local speech core for OpenCode, Claude Code, and future Emacs adapters.
Audio engines remain external and replaceable; client adapters only handle UI
events and prompt insertion.

* Current Providers

- STT: local =whisper-cli= from Whisper.cpp
- Recording: =sox=
- TTS: macOS =say=
- Claude STT: Claude Code's native hold-to-talk mode

No audio or transcript is sent to a remote service by this implementation.

* Install Prerequisites

#+begin_src bash
brew install whisper-cpp sox
mkdir -p ~/.local/share/whisper-cpp
curl -L -o ~/.local/share/whisper-cpp/ggml-large-v3-turbo-q5_0.bin \
  https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-large-v3-turbo-q5_0.bin
#+end_src

The model download is intentionally manual because it is large. Select a
different model with =VOICE_WHISPER_MODEL=/absolute/path/model.bin=.

* CLI

#+begin_src bash
voice/bin/voice doctor
voice/bin/voice record
voice/bin/voice stop
voice/bin/voice cancel
voice/bin/voice transcribe /path/to/audio.wav
voice/bin/voice speak --summary 'Long markdown response...'
#+end_src

Only transcription text is written to stdout. Status and errors use stderr, so
the CLI can be composed safely with client adapters.

* Configuration

| Variable                  | Default                                                   |
|---------------------------+-----------------------------------------------------------|
| =VOICE_STATE_DIR=         | =~/.cache/voice-interface=                                |
| =VOICE_SOX_COMMAND=       | =sox=                                                     |
| =VOICE_WHISPER_COMMAND=   | =whisper-cli=                                             |
| =VOICE_WHISPER_MODEL=     | =~/.local/share/whisper-cpp/ggml-large-v3-turbo-q5_0.bin= |
| =VOICE_MICROPHONE=        | system default                                            |
| =VOICE_SAY_COMMAND=       | =/usr/bin/say=                                            |
| =VOICE_TTS_VOICE=         | macOS default                                             |
| =VOICE_TTS_RATE=          | =210=                                                     |
| =VOICE_SUMMARY_CHARS=     | =400=                                                     |
| =VOICE_SUMMARY_SENTENCES= | =3=                                                       |
| =VOICE_SUMMARY_SOFT_STOP= | =0= (disabled)                                            |

How much of a response gets spoken is bounded by three limits, whichever hits
first: =VOICE_SUMMARY_SENTENCES= sentences, =VOICE_SUMMARY_CHARS= characters
(cut on a word boundary), and =VOICE_SUMMARY_SOFT_STOP= — an early stop once the
summary reaches that many characters, disabled by default. Set the soft stop to a
low value for terse announcements; to hear (nearly) the whole response use
=VOICE_SUMMARY_SENTENCES=999 VOICE_SUMMARY_CHARS=100000=.

* OpenCode

Merge =adapters/opencode/tui.json.example= into
=~/.config/opencode/tui.json=, then restart OpenCode.

| Action                      | Command          | Key              |
|-----------------------------+------------------+------------------|
| Start recording             | =/stt-record=    | =Ctrl-x r=       |
| Transcribe and submit       | =/stt-submit=    | =Ctrl-x g=       |
| Cancel recording            | =/stt-stop=      | =Ctrl-g=         |
| Stop current speech         | =/tts-stop=      | =Ctrl-x s=       |
| Speak full last response    | =/tts-speak=     | =Ctrl-x a=       |
| Speak selected text         | =/tts-selection= | =Ctrl-x Shift-s= |
| Cycle automatic speech mode | =/tts-mode=      | =Ctrl-x v=       |
| Show voice diagnostics      | =/voice-status=  | none             |

Automatic TTS defaults to =final= mode, which speaks a short summary only after
the final assistant response completes and ignores intermediate tool-call
messages. =/tts-mode= cycles through =final=, =live=, and =off=. =live= is the
speculative mode: it buffers complete sentences and speaks while the response
streams, so tool-progress text may be audible. Fenced code blocks are skipped.
Starting a new response, starting a recording, selecting text to speak, or
running =/tts-stop= interrupts current playback and clears queued sentences.

OpenCode normally copies a mouse selection to the macOS clipboard and clears the
visual selection on mouse-up. =/tts-selection= first reads an active OpenTUI
selection and then falls back to =pbpaste=, so invoke it immediately after
selecting the desired text. Selection alone does not trigger speech.

* Claude Code

Claude native voice handles STT. The shared CLI replaces the custom TTS script
for response output. Merge =adapters/claude/settings.json.example= into
=~/.claude/settings.json=.

The Stop hook must remain asynchronous. The CLI reads Claude's
=last_assistant_message= hook field, extracts a short Markdown-safe summary, and
invokes the configured TTS provider. Transcript parsing remains only as a
fallback for older Claude versions because transcript writes can lag behind the
Stop event.

* macOS Microphone Permission

macOS grants microphone access to the host application. For Alacritty, enable
Alacritty under System Settings, Privacy & Security, Microphone. For a terminal
inside Emacs.app, run =exec/emacs-mic-patch.sh= after each Emacs upgrade, then
approve the microphone prompt.
